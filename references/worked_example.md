# 실사례: 비렉스(매트리스) 4세그 패널 — 2026-10 실행 기준

브리프가 "코웨이 BEREX 침대(매트리스) — 국내 침대 판매 1위 Fact로 대세감, 스마트·안마 매트리스 확장, 렌탈"이었을 때의 전 과정. **본문 규칙이 이 예시보다 우선한다.** (이전 판의 예시는 세그를 데모(고소득·전문직)로 걸렀는데, 본문 3단계가 금지한 방식이라 교체했다.)

## 1. 브리프 파싱 + 웹 근거화
비렉스 = 코웨이의 매트리스·수면 브랜드. 웹서치로 확인한 사실:
- 제품 라인: 일반 매트리스(검증·내구) / 스마트 매트리스(수면센서·앱) / 안마 매트리스·모션베드.
- 판매 모델: 렌탈 + 방문 케어.
- 니모트론 직접 신호(`--deep` 11컬럼): 매트리스 0 · 렌탈 1 · 월정액 0 → 렌탈 수용은 finance_persona의 고정비 민감도로 **대리 측정**하는 축으로만 둔다(세그로 못 세움).

## 2. 세그 가설 (게이트 A) — 판별 기준 = 행동, 하드 필터 = 그 행동
| 세그 | 판별 기준(행동) | 하드 필터(그물) | 데모 = 가점만 |
|---|---|---|---|
| A 헤리티지 보수형 | 검증된·내구성·오래 쓰는 것을 산다 | finance+detailed의 '검증된·내구성·오래 쓰·튼튼한·질 좋은…' − 금융·비유 문맥 | 자가·소득·40대+ |
| B 수면문제×기기 수용형 | 잠을 못 자고, 기기·앱으로 해결하려 한다 | 신체 컬럼의 수면 문장(비유 '설칠 정도로' 제거) × 테크 표현 | 개방성 |
| C 신체 회복형 | 몸이 뻐근하고 회복 루틴이 있다 | 통증·뻐근·굳은·결림·파스 × 사우나·목욕·스트레칭·안마·요가 | 40대+ |
| D [역발상] 가성비 탐색형 | '많이 팔린다'가 아니라 내가 비교해서 싸게 | 최저가·가격 비교·전단지·쿠폰·마감 세일·핫딜·단돈 | 성실성 |

정규식은 `references/net_patterns.md`. 스캔은 `signal_scan.py gh --re ... --neg ... --body`.

## 3. 사용자 확정 (게이트 B)
4세그 × 3명, 30·40·50대(30~69세), 월정액 축 포함, 2-b로 넘길 패널(handoff).

## 4. 캐리어 매칭
```python
pool, rg_used, scanned = npq.load_adaptive(columns=[...51컬럼...], filter_fn=<세그 그물>, min_rows=60)
# 실측: 네 세그 모두 rg0(13,909행) 하나로 60명 충족
```
1. **풀 점검** — 실제 선발 풀에서 무작위 25명을 읽어 0점 비율. 실측(rg0): A 35%(→ 173명 전수 읽기, 0점 제외 112~114명) · B 0~8% · C 0~8% · D 4~12%.
2. **점수 = 후보 축소용** — 행동 키워드 가중합 + 데모 가점 + Big5 t점수×0.02(동점 깨기).
3. **읽기로 확정** — 점수 상위 15명 원문 → 적합(2점) 중 다양성 최소 규칙(성별·연령대)만 맞춰 3명. 각자 `fit_quotes`.
   - A 예: "유행을 타는 화려한 명품보다는 품질이 검증된 기본 아이템에 투자"
   - B 예(교집합 — 두 문장): "밤잠을 설칠 때면 유튜브에서 명상 음악을 찾아 틀어놓고 억지로 잠을 청합니다"
   - 오탐 예: '신제품' 키워드가 빵집 신제품을 잡아 69세 주부가 B에 들어옴 → 인용 불가 → 교체.
4. **선발 감사** — 🔴는 적합 인용 없음·풀 점검 실패·전원 동점뿐. n=3의 학력·가구 3/3은 🟡 기록.

## 5. 합성 + 산출
각 실제 인물(uuid 보존) 위에:
- 실제 소득·가구·Big5·취미 → `Q`
- 세그 근거·축 값의 근거 → `Q-derived`
- 미디어 습관·침대에서 하는 일 등 서술에 없는 것 → `INF`(근거 괄호)
- 브랜드 선호 → 부여 안 함, `가설`로만
- 인지 경계 — 매트리스는 전국 광고 카테고리라 "이름만 / 기본 기능까지 / 앱·센서까지"로 단계화

`render_panel` · `save_xlsx` · `save_panel_json` → 산출 3종, 부속 `selection_log.json` · `selection_audit.md` · `handoff_pool.json`.
