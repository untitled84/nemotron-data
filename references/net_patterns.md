# 그물(하드 필터) 패턴 — BEREX 실측 (2026-10-16)

5단계 '그물과 읽기의 분업'의 근거와 재사용 가능한 패턴. 세그 정의가 비슷하면 여기서 출발해 넓힌다. **그물은 재현율 담당이다 — 정밀도는 풀 점검(읽기)으로 잡는다.**

## 측정 방법
세그별 (1) 좁은 그물 풀 무작위 25 (2) 넓은 그물에만 걸린 25 (3) rg1 30~69세 무작위 300 — 500명을 라벨 없는 LLM 심사자가 원문으로 0/1/2 채점. 재현율 = 그물 안 진짜 ÷ (그물 안 + 넓은 그물에만 + 그물 밖 진짜 추정, 층별 가중). v2 수정 후 **튜닝에 안 쓴 새 표본 25명**으로 정밀도 재검증.

| 세그 | 풀 v1→v2 | 재현율 v1→v2 | 새 표본 0점(문맥 오탐) |
|---|---|---|---|
| A 검증·내구성 소비 | 201→157 | 100→100% | 24% → 전수 읽기 대상 |
| B 수면×기기 | 100→371 | 40→96% | 8% |
| C 통증×회복 루틴 | 1,033→1,289 | 74→91% | 12% |
| D 최저가·비교 행동 | 269→418 | 43→83% | 12% |

교훈 둘: ① 튜닝한 라벨로 잰 정밀도는 과적합(A 62%로 보였다가 새 표본 48%). ② 같은 기준이어도 심사자마다 1/2점 경계가 크게 다름(B 2점 22%↔8%) — **지표는 0점 비율**.

## 패턴 (Python re)
